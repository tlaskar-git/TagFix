TagFix

Tag what is wrong on screen, get a fix list out.

Hotkeys

Ctrl+Shift+T Arm or disarm the overlay (changeable in Settings)
Esc Cancel the open tag entry, or disarm
Enter Save the tag and stay armed for the next one
Shift+Enter Newline inside the tag text
Ctrl+Shift+R Open review and export

The flow

  1. Press Ctrl+Shift+T. A red frame and an ARMED badge appear and the cursor becomes a crosshair. If the screen looks wrong instead, TagFix disarms itself after a few seconds; run the diagnosis below and send the output.
  2. Drag a box around the thing that is wrong. Release.
  3. Type what is wrong in the popover. Pick severity (high, medium, low) and area (layout, copy, a11y, behaviour, other) or keep the defaults.
  4. Press Enter. You are armed again; tag the next thing.
  5. Press Esc when done.
  6. Press Ctrl+Shift+R, tidy the list (drag to reorder, click text to edit, drop what you do not want), then press Export fix list.

Export writes three files into the sweep folder and puts a pointer to brief.md on the clipboard: fixlist.md (evidence ledger), fixlist.html (single file, opens anywhere offline), brief.md (agent brief with one task and acceptance criterion per tag).

Where things live

Sweeps land in a sweeps folder next to tagfix.exe, one folder per sweep with sweep.json plus the tag PNGs. Change the location in Settings (tray icon, Settings).

Command line

tagfix sweep new <slug> Create a sweep folder for today
tagfix sweep list List sweeps with tag counts
tagfix diag Print a machine report (WebView2, monitors, hotkeys) and write tagfix-diag.txt; send this if something misbehaves
