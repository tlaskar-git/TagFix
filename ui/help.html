TagFix

Tag what is wrong on screen, get a fix list out.

Controls

Ctrl+Shift+T Arm or disarm (changeable in Settings)
Ctrl+Shift+drag While armed: mark a region to tag
Ctrl+Shift+S While armed: the next plain drag marks a region, no keys held. Easier on a laptop trackpad
Enter Save the tag and hand the screen straight back to you
Shift+Enter Newline inside the tag text
Esc Cancel the tag you are typing
Ctrl+Shift+R Open review and export

The flow

  1. Press Ctrl+Shift+T. A small ARMED badge appears. Keep working normally: armed is a standby state, your clicks, typing, and scrolling all behave exactly as usual.
  2. When you see something wrong, hold Ctrl+Shift and drag a box around it with the left mouse button. On a trackpad, where holding two keys through a click is awkward, press Ctrl+Shift+S instead: the badge turns to DRAG NOW and your next ordinary drag marks the region.
  3. Release. A popover opens: type what is wrong, and pick severity (high, medium, low) and area (layout, copy, a11y, behaviour, other) or keep the defaults.
  4. Press Enter. The tag is saved and the screen is yours again, still armed. Mark the next thing the same way whenever you like.
  5. Press Ctrl+Shift+T again to disarm. Ctrl+Shift+drag then does nothing.
  6. Press Ctrl+Shift+R, tidy the list (drag to reorder, click text to edit, drop what you do not want), then press Export fix list.

Only Ctrl+Shift+left click is taken while armed. Every other key and click, Esc included, goes to your own apps untouched.

Export writes three files into the sweep folder and puts a pointer to brief.md on the clipboard: fixlist.md (evidence ledger), fixlist.html (single file, opens anywhere offline), brief.md (agent brief with one task and acceptance criterion per tag).

Where things live

Sweeps land in a sweeps folder next to tagfix.exe, one folder per sweep with sweep.json plus the tag PNGs. Change the location in Settings (tray icon, Settings).

Command line

tagfix sweep new <slug> Create a sweep folder for today
tagfix sweep list List sweeps with tag counts
tagfix diag Print a machine report (WebView2, monitors, hotkeys) and write tagfix-diag.txt; send this if something misbehaves
