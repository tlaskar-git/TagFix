      TagFix

      Tag what is wrong on screen, get a fix list out.

      Controls

      Ctrl+Shift+T Arm or disarm (changeable in Settings)
      Ctrl+Shift+drag While armed: mark a region to tag
      Ctrl+Shift+S While armed: the next plain drag marks a region, no keys held. Easier on a laptop trackpad
      Ctrl+Shift+Q While armed: turn the text you just highlighted into a quote tag (changeable in Settings)
      pen chip The small round pen button that appears below right of a highlight for four seconds. Clicking it does the same as Ctrl+Shift+Q. The click never reaches the app underneath, so your selection survives. Turn it off in Settings
      Ctrl+Shift+A While armed: the next drag attaches a comparison crop to the tag you just saved (changeable in Settings)
      Enter Save the tag and hand the screen straight back to you
      Shift+Enter Newline inside the tag text
      Ctrl+Up In the popover: recall the note and the chips from your last save, to edit rather than retype
      Esc Cancel the tag you are typing
      Ctrl+Shift+R Open this window at Review and export

      The tray icon

      TagFix lives in the system tray and has one window, this one, with three sections in the sidebar: Review, Settings and How to use.

      double click Open the window at Review and export
      right click The menu: Arm / disarm, Quote highlight, Review and export, Settings, How to use, Open sweeps folder, Quit
      single left click Nothing, so the first click of a double click does not pop the menu

      Closing this window only hides it, so reopening is instant and a Capture after you started keeps working while you drag on screen. Quit in the tray menu is what exits TagFix.

      The flow

      1. Press Ctrl+Shift+T. Keep working normally: armed is a quiet standby state, marked only by a thin frame at the edge of the screen. Your clicks, typing, and scrolling all behave exactly as usual.
      2. Something looks wrong: hold Ctrl+Shift and drag a box around it with the left mouse button. On a trackpad, where holding two keys through a click is awkward, press Ctrl+Shift+S instead: a short DRAG NOW prompt appears and your next ordinary drag marks the region.
      3. Something reads wrong: highlight the text as you would before a copy. The pen chip appears beside it; click it, or press Ctrl+Shift+Q. The popover opens with the quote in a scrollable block above the note box. No screenshot is taken unless you turn that on in Settings.
      4. Type what is wrong, and pick severity (high, medium, low), area (layout, copy, a11y, behaviour, other) and target (which product this is about) or keep the defaults. The target is preselected from the page address when TagFix can read it. The note box spellchecks. Ctrl+Up brings back your last note and chips.
      5. Press Enter. The tag is saved and the screen is yours again, still armed. To add a second crop to that same tag, a before and after or a comparison, press Ctrl+Shift+A and drag: the crop joins the tag instead of starting a new one.
      6. Press Ctrl+Shift+T again to disarm. Ctrl+Shift+drag then does nothing.
      7. Press Ctrl+Shift+R for the Review section: drag rows to reorder, click text to edit, click a thumbnail to enlarge it, drop what you do not want. New sweep starts a fresh one: type a name in the box beside the button and press Enter. Carry forward copies tags out of an earlier sweep into this one as re-reports, keeping the original picture; a carried row then offers Capture after, which takes one fresh crop and stores it beside the original.

      Only Ctrl+Shift+left click and a click on the pen chip are taken while armed. Every other key and click, Esc included, goes to your own apps untouched.

      Getting it out

      Copy for chat puts the whole sweep on the clipboard as Markdown, ready to paste into a chat window; Copy as text does the same without the Markdown syntax. Neither needs an export first. Open opens any of the five files in its default app, Save as writes one wherever you choose, and Export writes all five into the sweep folder and copies a pointer to brief.md to the clipboard:

      fixlist.mdthe full evidence ledger
      fixlist.html the same, single file, images inlined, opens offline
      brief.md agent brief, one task and acceptance criterion per tag, grouped by target
      feedback.mdthe chat ready sheet
      feedback.txtthe same in plain text

      If a target has an export directory set in Settings, Export also drops that target's own tags and images into a folder there, named after the sweep.

      Where things live

      Sweeps land in a sweeps folder next to tagfix.exe, one folder per sweep with sweep.json plus the PNGs. Change the location in the Settings section. sweeps/active.txt names the sweep currently being written to.

      tag-NN.pngthe crop
      tag-NN-context.png the whole window at reduced size with the crop outlined in red, so the crop can be placed later
      tag-NN-a1.png an attachment (a2, a3 and so on for the next ones)
      tag-NN-before.png the original picture of a carried tag
      tag-NN-quote.png the optional window screenshot of a quote tag

      Known limits

      • A quote tag is read by borrowing the clipboard for a moment. TagFix puts your text back afterwards, but it cannot put back an image or a copied file: if that is what was on the clipboard, it is gone.
      • In a terminal with nothing selected, Ctrl+C is an interrupt. The quote gesture is deliberate for that reason: highlight first.
      • The page address is read from Chrome, Edge and Firefox only. Anywhere else the URL stays empty, and so does the target unless you pick one yourself.

      Command line

      tagfix sweep new <slug> Create a sweep folder for today
      tagfix sweep list List sweeps with tag counts
      tagfix diag Print a machine report (WebView2, monitors, hotkeys) and write tagfix-diag.txt; send this if something misbehaves
